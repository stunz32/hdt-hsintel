# Phase 6 – Sequencing Rules (Stub)

Objective: establish consistent, low-risk action ordering used by the coach and fast-paths. Rules are informational only for Phase 6; scoring remains unchanged.

- Information First
  - Prefer low-risk probes that reveal secrets or state: small face poke, cheap spell, small trade.
  - Avoid committing premium resources before information checks.

- Buffs Before Summons
  - Apply hand/board buffs to existing minions before summoning new ones (maximize buff coverage).

- Small Spells First
  - Cast lowest-cost, non-critical spells before high-impact spells to trip reactive secrets with minimal downside.

- Trades Before Face when Taunts Present
  - Clear all opponent taunts with the minimal number of attacks before any face attacks.

- Highest Impact Last
  - Delay irreversible/high-risk plays (e.g., big removal, all-in buffs) until after probes resolve.

- Summon Placement
  - Place new minions to preserve adjacency effects where relevant (left-to-right fill).

- End Turn Safety
  - Reserve 2 mana for Hero Power only when it aligns with plan value; otherwise prioritize tempo.

Note: Phase 6 does not modify public models or engine scoring. These rules inform future micro-phases and logging.
